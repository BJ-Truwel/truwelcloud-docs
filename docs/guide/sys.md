### 站点管理

<div align=center>
<span style="width:50%;display:inline-block">

![](../_media/sys_station.webp)

</span>
<span style="width:50%;display:inline-block">

![](../_media/sys_station_field.webp)

平台按`站点` → `系统` → `数据表`三级结构组织数据，`数据表`层下可继续划分为`数据`、`图片`与`文件`三类。

> 平台已支持 `Campbell 数据`、`MQTT 消息`、`本地文件`等主流数据类型，其他类型可按需定制开发。
